GOIÁS RP — LAUNCHER ANDROID
=============================

Primeira versão do projeto:
- Visual azul/preto
- Nome PikeFelipe
- IP/porta centralizados no código
- Botões Baixar/Atualizar e Jogar
- Base pronta para integrar o sistema de arquivos/mods

CONFIGURAÇÃO DO SERVIDOR
Edite MainActivity.java:
SERVER_IP = "SEU_IP_AQUI";
SERVER_PORT = 7777;

IMPORTANTE
Este projeto é um launcher. Ele não contém arquivos proprietários do GTA San Andreas nem um cliente SA-MP de terceiros. A integração com o jogo e a distribuição de mods deve usar arquivos/licenças que você tenha autorização para distribuir.

Para compilar:
1. Abra a pasta no Android Studio.
2. Aguarde o Gradle sincronizar.
3. Build > Build APK(s).
